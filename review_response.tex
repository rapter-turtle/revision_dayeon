\reviewer
\section*{\normalsize{Reviewer 1}}

This manuscript proposes MSGAT, a metapath-based heterogeneous graph neural network for herb-phenotype association prediction. The method combines an incremental metapath-selection strategy with a sequential cross-type update mechanism, in which compound, herb, and phenotype representations are updated in a predefined order and newly updated representations are immediately used by subsequent node types. The topic is relevant to computational natural-product discovery, and the manuscript is generally clear. The large heterogeneous graph constructed from CODA and COCONUT and the Parkinson's disease case study are also potentially valuable. However, several methodological issues need to be addressed before the conclusions can be considered sufficiently supported. In particular, the current description of graph construction raises a serious concern regarding possible target-edge leakage; the proposed cross-type synchronization mechanism is not directly evaluated in the ablation study; the metapath-selection procedure requires a clearer separation between model selection and final evaluation; and stronger heterogeneous-graph baselines are needed.

%%%%%%%%%%%%%%%% R1.1 %%%%%%%%%%%%%%%%
\begin{revcomment}
\textbf{The train/validation/test protocol needs to be clarified.} The manuscript states that positive herb-phenotype edges are split into training, validation and test sets, and that a graph is generated for each split. Please clarify whether validation/test target edges are removed from the message-passing graph and from metapath construction. If target edges remain in the input graph, this would lead to information leakage.
\end{revcomment}

\begin{revresponse}
\PENDING{All experiments must be rerun under the corrected protocol. The code fix is done.}

\textcolor{blue}{We thank the Reviewer for this comment; the concern was justified. In the original implementation, reverse edges were handled consistently with their forward edges, but the graph used at evaluation retained the herb--phenotype edges of that split. Validation and test target edges were therefore present during message passing and in the metapath-based adjacency at evaluation time.}

\textcolor{blue}{We have corrected this. One input graph, containing all non-herb--phenotype edges and only the training herb--phenotype edges with their reverse edges, is now used for training, validation and testing. Validation and test edges are used only as prediction targets. Metapath-based adjacency is computed from this input graph, so metapath neighbors derive from training edges only, and each run checks automatically that no held-out edge remains in the graph in either direction. All results were regenerated under this protocol, so the values in the revised manuscript differ from the original submission. The revised text and the pseudocode are shown under Reviewer 4, Major Comment 1.}
\end{revresponse}

\begin{revcomment}
\textbf{The mathematical formulation of the link predictor may not capture herb--phenotype-specific interactions.}

The manuscript defines the association prediction function as:
\[ p_{uv} = \sigma\left( W_l^\top [z'_u \,\|\, z'_v] + b_l \right). \]
Assuming Equation 14 describes a single affine transformation followed by a sigmoid, the score can be rewritten as:
\[ p_{uv} = \sigma\left( w_H^\top z'_u + w_P^\top z'_v + b_l \right). \]
This is an important limitation because the resulting score is additively separable into herb-specific and phenotype-specific contributions.

Consequently, once the node embeddings are fixed, the relative ranking of herbs would be identical for every phenotype. The predictor would not directly model pairwise compatibility between a particular herb and a particular phenotype.

For a method specifically designed to identify biologically meaningful herb--phenotype associations, this limitation is particularly concerning.

The authors should clarify whether Equation 14 accurately represents their implementation. Figure 1 depicts an MLP-based predictor, which may imply a more expressive architecture than the mathematical formulation currently describes.

If the implemented decoder is indeed a single affine layer, I recommend evaluating alternative association functions that explicitly model interactions, such as:
\[ p_{uv} = \sigma\left( z'^{\top}_u W z'_v + b \right), \]
or a multilayer perceptron containing nonlinear hidden layers.

An ablation comparing additive, bilinear, dot-product, and nonlinear MLP decoders would help establish whether the reported performance reflects meaningful herb--phenotype compatibility or primarily node-level association propensities.

This concern also has direct implications for the biological specificity of the Parkinson's disease case study.
\end{revcomment}

\textbf{Reproducibility, random node features, and generalizability require further attention.}
